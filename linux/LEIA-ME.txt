ArmorPaint - Linux x64
======================

Pacote gerado pelo GitHub Actions (ubuntu-24.04), compativel com
Linux Mint 22.3 / Ubuntu 24.04 (x86_64).


COMO EXECUTAR
-------------
1. Descompacte (dentro da pasta onde voce baixou):

     tar -xzf ArmorPaint-Linux-x64.tar.gz

   Isso cria a pasta ArmorPaint-Linux-x64.

2. Rode o programa:

     cd ArmorPaint-Linux-x64
     ./ArmorPaint.sh

   O ArmorPaint.sh e necessario porque o programa procura a pasta
   data/ ao lado do executavel.


ATALHO NO MENU (OPCIONAL)
-------------------------
     cd ArmorPaint-Linux-x64
     ./instalar-desktop.sh

Depois abra o menu e procure por "ArmorPaint".


DEPENDENCIAS
------------
O executavel e dinamico. No Linux Mint 22.3 / Ubuntu 24.04 as
bibliotecas costumam vir instaladas. Se faltar alguma:

     sudo apt install libvulkan1 mesa-vulkan-drivers

Para desenvolvimento (recompilar localmente):

     sudo apt install make clang libvulkan-dev libgtk-3-dev libssl-dev \
       libxi-dev libxrandr-dev libxcursor-dev libasound2-dev


SE NAO ABRIR
------------
1. Veja a saida no terminal:

     ./ArmorPaint.sh

2. Confirme que ha driver Vulkan:

     vulkaninfo --summary

   Em GPU Intel/AMD, instale:

     sudo apt install mesa-vulkan-drivers
